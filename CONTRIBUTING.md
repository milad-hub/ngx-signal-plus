# Contributing to ngx-signal-plus

The full contributing guide lives with the library it describes:

**[projects/signal-plus/CONTRIBUTING.md](projects/signal-plus/CONTRIBUTING.md)**

It covers the local toolchain, the development workflow, testing rules, the
consumer smoke builds, the branch and merge policy, coding standards, and the
release process.

This file exists because GitHub only detects a contributing guide at the
repository root, in `.github/`, or in `docs/`. Rather than keep two copies that
drift apart, this one points at the real guide.

Quick links:

- [Code of Conduct](.github/CODE_OF_CONDUCT.md)
- [Security policy](SECURITY.md)
- [Report a bug](https://github.com/milad-hub/ngx-signal-plus/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/milad-hub/ngx-signal-plus/issues/new?template=feature_request.yml)
